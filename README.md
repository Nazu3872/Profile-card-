# Nazmunnahar Nazu — Developer Profile Card

A modern, responsive, and crafted Developer Profile Card built with semantic HTML5, modern CSS3, and vanilla JavaScript. Features an ink-dark aesthetic, quiet typography, authentic portrait photography, and interactive tabs for technologies and projects.

---

## 🎯 Features

- **Ink Dark Aesthetic:** Built on a restrained charcoal-ink neutral ramp with quiet hairline borders, zero flashy AI slop, no distracting looping animations, and no purple gradient wash.
- **Authentic Portrait Visual:** Circular portrait frame displaying the real developer photo with graceful fallback support.
- **Accessible Tabs:** Seamless tabbed interface to switch between **Technologies**, **Featured Projects**, and **Curriculum & Journey**.
- **11 Curated Technologies:** Full stack stack showcase including HTML5, CSS3, JavaScript, TypeScript, React.js, Next.js, Node.js, Express.js, Tailwind CSS, Git, and GitHub with uniform Lucide line iconography.
- **Quick Actions:** Direct links to GitHub profile, LinkedIn, live portfolio website, and an interactive one-click "Copy Email" utility with toast feedback.
- **Mobile First & Responsive:** Adapts cleanly across mobile screens, tablets, and desktop displays.

## 🛠️ Local Setup & Preview

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Nazu3872/Profile-card-.git
   cd Profile-card-
   ```

2. **Open in browser:**
   - Double-click `index.html` to open it directly in any modern browser.
   - Or use VS Code's **Live Server** extension (right-click `index.html` → *Open with Live Server*).

---

## 🚀 How to Deploy on GitHub Pages

1. Go to your repository on GitHub: [`https://github.com/Nazu3872/Profile-card-`](https://github.com/Nazu3872/Profile-card-)
2. Click on **Settings** (top tab bar).
3. In the left sidebar, click on **Pages**.
4. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
5. Under **Branch**, select `main` and folder `/ (root)`.
6. Click **Save**.
7. Within 1-2 minutes, your website will be live at:
   `https://nazu3872.github.io/Profile-card-/`
